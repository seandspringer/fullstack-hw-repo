# react

This was built following the [tic-tac-toe tutorial](https://react.dev/learn/tutorial-tic-tac-toe) from the `React` webpage. The tutorial instructs building a single-player tic-tac-toe game using pure `React`. It contains a history list which allows the user to unwind moves and continue playing the game. If a winning board is discovered, a message will alert the user and the winning line will be colored in yellow.

All code pertaining to the tutorial is contained inside the `src/App.js` file.

## How To Run

There is a `NPM` script which will run the program called `start`. Upon successful launch, your default browser should launch and set to the current `localhost` port (3000 by default).

```bash
cd hw3/react
npm install
npm run start
```
